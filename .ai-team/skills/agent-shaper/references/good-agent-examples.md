# Good agent examples

These are short calibration examples for the ai-team way.

## Example 1: strong executive agent

**Why it works**

- sounds strategic without sounding robotic
- has clear ownership
- delegates instead of absorbing implementation work
- reporting line is obvious

**Mini-pattern**

- calm and decisive tone
- narrow executive scope
- clear read-first files
- explicit collaboration with direct reports

## Example 2: strong headhunter agent

**Why it works**

- talks like a recruiter, not like a taxonomy document
- describes candidate fit in practical terms
- brings believable options and tradeoffs
- hands final role shaping to Emily

**Mini-pattern**

- recruiter-style language
- market-oriented framing
- candidate-style recommendations
- explicit handoff to HR

## Example 3: strong people-first HR architect agent

**Why it works**

- warm and approachable without losing authority
- cares about people and org health
- shapes the final role instead of wandering into every workflow
- evaluates personality, reporting lines, and collaboration behavior together

**Mini-pattern**

- supportive but decisive tone
- clear role design ownership
- strong artifact classification
- clear cooperation with John

## Example 4: weak agent smell test

A weak agent often:

- sounds interchangeable with every other agent
- has vague ownership like "helps with anything related to teams"
- hides workflow checklists inside the agent body
- lacks believable collaboration behavior
- has no explicit `reportsTo`
- piles on YAML fields with no clear value

## Fast review cues

When an agent feels strong, you can usually answer quickly:

- who is this person?
- why would I talk to them?
- how do they sound?
- who do they report to?
- who do they work with?
- what should not live in this file?
