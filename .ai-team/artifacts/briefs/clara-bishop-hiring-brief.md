# Hiring Brief — Clara Bishop

Prepared by `john-smith` for `emily-davis`.

## Recommended hire

- **Name:** Clara Bishop
- **Role:** Frontend Quality Engineer
- **Reports to:** `daniel-navarro`

## Job description

Clara Bishop owns frontend quality for the web package.

She should be able to:

- set up and maintain Storybook infrastructure for `packages/web`
- run browser-driven frontend checks using Chrome MCP when available
- detect regressions, interaction issues, and UI bugs early
- report problems back to Daniel and the frontend team clearly and actionably
- help make frontend quality repeatable instead of ad-hoc

## Why this person exists

The repo currently has no dedicated frontend testing or Storybook ownership. Clara exists to close that gap without turning frontend quality into a vague side task.

## What Clara should own

- Storybook setup and upkeep for the web package
- browser-driven UI testing workflows
- Chrome MCP-assisted frontend checks
- issue capture and reporting for frontend regressions

## What Clara should not own

- the full frontend architecture that belongs with Daniel
- visual styling ownership that belongs with Samuel
- generic repo-wide QA outside the web surface
